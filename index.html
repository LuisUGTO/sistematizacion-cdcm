Captura de actividades

1. Clasificación y ubicación

Selecciona la clasificación institucional correspondiente antes de registrar la actividad.

Selecciona una acción para cargar su configuración.
Selecciona primero el municipio.

2. Persona responsable Opcional

Es la persona responsable de la actividad. Puede ser distinta de quien está capturando el registro.

3. Personas atendidas

Registra únicamente las cifras reportadas para la actividad. Los campos pueden variar según la acción seleccionada.

Cómo se leen estas cifras Beneficiarios: personas únicas atendidas directamente. Participantes: personas que participaron activamente. Accesos: asistencias, entradas o participaciones; pueden repetirse. No se dividen ni se suman entre sí. Grupo prioritario es un dato complementario y puede coincidir con género o edad.

Desagregación demográfica

Captura las cifras disponibles para cada grupo de población. El sistema no completa valores automáticamente.

4. Detalle de taller / capacitación

5. Evidencias Opcional

Puedes adjuntar varias evidencias ahora o completar este paso después desde Bitácora. Formatos: JPG, PNG, WEBP o PDF; máximo 10 MB por archivo.

Controles institucionales

Herramientas administrativas disponibles únicamente para el rol administrador. Todas las decisiones sensibles conservan trazabilidad y requieren confirmación explícita.

Depuración de registros

Revisa registros manuales o importados desde Bitácora y retira los que ya no se necesiten. El retiro conserva trazabilidad y protege los registros históricos.

Usuarios, alcances y catálogos

Gestiona roles, unidades y municipios de cada persona, además de los catálogos operativos disponibles para administración.

Para proteger la operación, este módulo no realiza borrado físico. Solo ADMIN puede retirar registros y debe indicar un motivo y una confirmación explícita antes de ejecutar la acción.
